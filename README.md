# Queue Using Array

**A Data Structures and Algorithms (DSA) Project by Sanjyoti Das**

## 📌 About the Project

This project demonstrates the implementation of a **Queue Data Structure using an Array**. A queue is a linear data structure that follows the **FIFO (First In, First Out)** principle, meaning the element inserted first is removed first.

The project helps beginners understand how queues work and how their basic operations are implemented using an array.

## 🎯 Objectives

- Understand the concept of a queue.
- Implement queue operations using an array.
- Learn the FIFO principle.
- Understand insertion, deletion, and traversal in a queue.
- Practice fundamental data structure concepts.

## ⚙️ Features

- **Enqueue:** Insert an element at the rear of the queue.
- **Dequeue:** Remove an element from the front of the queue.
- **Peek / Front:** View the first element without removing it.
- **Display:** Show all elements currently in the queue.
- **Overflow Handling:** Detect when the queue is full.
- **Underflow Handling:** Detect when the queue is empty.

## 🧠 Queue Operations

| Operation | Description |
|---|---|
| Enqueue | Adds an element to the rear |
| Dequeue | Removes an element from the front |
| Peek | Returns the front element |
| Display | Prints the queue elements |

## 📊 Example

Suppose we insert `10`, `20`, and `30` into the queue.

**After Enqueue:**

`Front → [10] [20] [30] ← Rear`

After performing `Dequeue`, the element `10` is removed.

**Updated Queue:**

`Front → [20] [30] ← Rear`

This demonstrates the FIFO principle.

## ⏱️ Time Complexity

| Operation | Time Complexity |
|---|---|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Peek / Front | O(1) |
| Display | O(n) |

*Note: These complexities assume a standard array-based queue implementation with front and rear indices. A shifting-array implementation may have O(n) dequeue time.*
